# 프로젝트 계획서

## 1. 프로젝트명
TasteLog - 나만의 맛집·카페 기록 웹페이지

## 2. 프로젝트 개요
TasteLog는 내가 방문한 맛집과 카페 정보를 간단하게 기록하고, 카드 형태로 모아 볼 수 있는 개인용 웹페이지입니다. 별도의 로그인이나 회원가입 없이, 브라우저에 데이터를 저장해서 나만의 맛집·카페 리스트를 관리하는 것을 목표로 합니다.

## 3. 개발 목적
- 방문했던 맛집·카페 정보를 흩어지지 않게 한 곳에 기록하기 위해서입니다.
- HTML, CSS, JavaScript만으로 실제로 동작하는 웹페이지를 처음부터 끝까지 만들어보며 바이브 코딩 개발 흐름(계획서 작성 → 단계별 기능 구현)을 연습하기 위해서입니다.

## 4. 주요 사용자
- 맛집·카페를 자주 다니고, 방문 기록을 개인적으로 남기고 싶은 사용자 (개발자 본인)
- 별도의 팀원이나 다수의 회원을 대상으로 하지 않는 개인용 서비스입니다.

## 5. 주요 기능
1. 가게 이름 입력
2. 맛집/카페 카테고리 선택
3. 지역 입력
4. 별점 선택 (예: 1~5점)
5. 한줄평 입력
6. 재방문 여부 선택 (예/아니오)
7. 등록한 장소를 카드 형태로 표시
8. 맛집/카페 필터 (카테고리별로 골라보기)
9. 기록 삭제

## 6. 화면 구성
한 페이지(단일 화면) 안에서 아래 영역들로 구성합니다.

- **입력 영역 (상단)**: 가게 이름, 카테고리, 지역, 별점, 한줄평, 재방문 여부를 입력하고 "등록" 버튼을 누르는 폼
- **필터 영역**: "전체 / 맛집 / 카페"를 선택할 수 있는 버튼 또는 탭
- **기록 목록 영역 (하단)**: 등록된 장소들이 카드 형태로 나열되는 영역. 각 카드에는 입력한 정보와 삭제 버튼이 표시됨
- PC 화면에서는 카드가 여러 열로, 모바일 화면에서는 한 열로 보이도록 반응형으로 구성합니다.

## 7. 사용 기술
- **HTML5**: 페이지 구조 작성
- **CSS3**: 레이아웃, 카드 디자인, 반응형 스타일링
- **JavaScript (Vanilla JS)**: 입력값 처리, 카드 생성/삭제, 필터링 로직
- **localStorage**: 로그인이나 서버, 데이터베이스 없이 브라우저에 기록 데이터를 저장
- 별도의 백엔드 서버나 데이터베이스는 사용하지 않습니다.

## 8. 개발 순서
1. **1단계 - 기본 구조**: HTML로 입력 폼과 기록 목록 영역의 뼈대 만들기
2. **2단계 - 등록 기능**: 입력한 정보를 카드 형태로 화면에 표시하기
3. **3단계 - 저장 기능**: localStorage를 이용해 새로고침해도 기록이 유지되도록 만들기
4. **4단계 - 필터 기능**: 맛집/카페 카테고리별로 골라 보는 기능 추가
5. **5단계 - 삭제 기능**: 각 카드에서 원하는 기록을 삭제하는 기능 추가
6. **6단계 - 디자인 다듬기**: 전체 스타일 정리 및 PC·모바일 화면 반응형 처리

## 9. 기대 결과
- 로그인이나 서버 없이도 브라우저만으로 나만의 맛집·카페 기록을 남기고 관리할 수 있는 웹페이지가 완성됩니다.
- 가게 이름, 카테고리, 지역, 별점, 한줄평, 재방문 여부가 카드 형태로 한눈에 정리되어 보입니다.
- 카테고리 필터와 삭제 기능을 통해 기록을 편리하게 관리할 수 있습니다.
- PC와 모바일 어디에서도 무리 없이 사용할 수 있는 화면 구성을 갖추게 됩니다.
