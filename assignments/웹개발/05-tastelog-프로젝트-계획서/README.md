# TasteLog 프로젝트 계획서

- 과목: 웹개발
- 날짜: 2026-08-19

## 설명

이 프로젝트 계획서는 바닐라 자바스크립트 기반의 나만의 맛집 및 카페 기록 웹 애플리케이션인 'TasteLog'의 개발 기획을 담고 있습니다. 별도의 로그인이나 백엔드 서버 없이 브라우저의 localStorage를 활용하여 사용자가 방문한 장소의 이름, 카테고리, 지역, 별점, 한줄평, 재방문 여부 등을 저장하고 관리할 수 있도록 설계되었습니다. 단일 페이지 구조 내에서 정보 입력 폼, 카테고리별 필터링, 카드 형태의 목록 표시 및 삭제 기능 등 핵심 기능의 명세가 정리되어 있습니다. 또한 HTML5, CSS3, Vanilla JS를 활용한 바이브 코딩 개발 흐름과 반응형 웹 디자인 구현을 주요 목적으로 명시하고 있습니다.
