# Moa 콘텐츠 아카이브 웹 서비스 프로젝트 계획서

- 과목: 웹개발
- 날짜: 2026-08-14
- 태그: 웹개발, 프로젝트기획, api연동, localstorage, 아카이브

## 설명

본 프로젝트는 영화, 드라마, 책, 음악 등 다양한 콘텐츠를 외부 API로 검색해 자동 정보를 수집하고, 사용자의 개인 취향 정보를 덧붙여 보관하는 아카이브 웹 애플리케이션 'Moa'의 기획 문서입니다. 서버와 데이터베이스 없이 브라우저의 localStorage를 활용하여 개인화된 감상 기록 관리 서비스를 구축하는 것을 목표로 합니다. 외부 API 검색 기반의 기록 자동 입력, 중복 등록 방지, 직접 추가, 필터 및 정렬, 즐겨찾기, 반응형 UI 등 상세 기능 사양과 서비스 흐름이 정의되어 있습니다. 외부 API 연동 및 상태 관리 중심의 웹 애플리케이션 개발 흐름을 종합적으로 계획하고 체계화한 자료입니다.
